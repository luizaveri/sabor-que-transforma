🍃 Sabor que Transforma

Alimentação consciente, sustentabilidade e transformação social.

O Sabor que Transforma é um projeto acadêmico de desenvolvimento web criado em equipe durante a graduação em Ciência da Computação. A iniciativa consiste na criação de um site institucional voltado à conscientização sobre alimentação saudável, consumo responsável e sustentabilidade.

O projeto busca apresentar informações e incentivar práticas que contribuam para uma relação mais consciente com os alimentos, promovendo acessibilidade alimentar, redução do desperdício e educação nutricional.

🎯 Objetivos do projeto

* Alimentação acessível: incentivar o acesso a uma alimentação equilibrada, nutritiva e acessível para todos.
* Redução do desperdício: apresentar formas de aproveitar melhor os alimentos e evitar descartes desnecessários.
* Educação alimentar: compartilhar conhecimentos e práticas que contribuam para escolhas alimentares mais conscientes.

⚙️ Desenvolvimento

Durante o desenvolvimento, foram aplicados conhecimentos de estruturação de páginas, estilização e programação Front-End.

A construção do site envolveu organização dos arquivos, elaboração da interface, aplicação de identidade visual e desenvolvimento das páginas institucionais.

Além dos conhecimentos técnicos, o trabalho proporcionou experiências de colaboração, comunicação, divisão de atividades e resolução de problemas em equipe.

📚 Aprendizados

O projeto proporcionou a oportunidade de transformar conhecimentos teóricos em uma aplicação prática, explorando conceitos fundamentais do desenvolvimento web.

Entre os principais aprendizados estão:

* Desenvolvimento de interfaces utilizando HTML e CSS.
* Aplicação de JavaScript em projetos web.
* Organização e estruturação de arquivos.
* Trabalho colaborativo e compartilhamento de conhecimentos.
* Desenvolvimento de soluções com propósito social.

🌱 Propósito

Acreditamos que pequenas mudanças de hábitos podem gerar grandes transformações. Por meio da tecnologia e da informação, o Sabor que Transforma busca contribuir para uma sociedade mais consciente, sustentável e comprometida com a alimentação.
